## What is a Premium Request?

A **premium request** is a request to GitHub Copilot (or a similar AI coding assistant) that uses an advanced, higher-capability AI model — such as Claude Sonnet, GPT-4o, or o3 — rather than the standard base model.

### Key points

| Aspect | Detail |
|--------|--------|
| **When it applies** | Any time Copilot routes your prompt to a premium model (e.g. for complex reasoning, multi-file edits, or agentic tasks). |
| **Quota** | Premium requests count against a separate monthly allowance that is distinct from ordinary (base-model) requests. |
| **Cost** | Each premium model has a different "multiplier". For example, a request using GPT-4o may count as 1 premium request, while a request using o3 may count as several. |
| **Free tier** | GitHub Free and GitHub Pro plans include a set number of premium requests per month at no extra charge. Once the allowance is exhausted, Copilot falls back to the base model (or prompts you to upgrade). |
| **Paid tier** | GitHub Copilot Individual / Business / Enterprise subscribers receive a larger monthly premium-request quota, and can optionally purchase additional capacity. |

### How to tell if a request was premium

- In the Copilot Chat UI, the model selector shows which model handled your message.
- In GitHub.com settings → *Copilot* → *Usage*, you can review your consumed premium-request quota.
